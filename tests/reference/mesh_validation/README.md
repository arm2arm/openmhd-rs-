# Periodic geometry and reconstruction evidence

Generated on 2026-11-04 from clean implementation revision `f275b49` with `python3 scripts/run_mesh_validation.py`.

`summary.csv` records volume-weighted L1/L2 vector-gradient errors for regular/jittered N8/16/32 meshes, raw/limited neighbour fits and raw face fits, plus geometry closure/area and stencil-condition diagnostics. `provenance.json` records source hashes, compiler, configuration, invocation and every refinement order.

See [predeclared gates, API details and measured interpretation](../../../docs/MESH_VALIDATION.md). This is a manufactured scalar/planar-curl study, not a fluid evolution or a general div(curl) validation.

The [separate AI review](../../../docs/MESH_AI_REVIEW.md) independently checked geometry, gradients, convergence tables and checksums.
