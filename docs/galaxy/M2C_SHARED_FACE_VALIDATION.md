# M2c shared-face curl validation

The opt-in selector `periodic-shared-face-quadratic-curl-v1` uses centroid point samples of the vector potential and cell averages of the magnetic field (`a-point-b-cell-average-v1`). Its first implementation uses the accepted periodic two-ring quadratic support with the registered three-ring rank fallback. The retained point-curl reference has its own point sampling. The scientific definitions, thresholds and follow-up physical gates are in [the shared-face specification](CURL_3D_MEAN_SPEC.md) and [independent design review](CURL_EVENT_DESIGN_REVIEW.md).

## Static map on native geometry

Use the unit periodic box, exact input order by index and the literal source words in [the small fixture](fixtures/m2c_shared_face_static_v1.json). The fixture contains a single real owner, an eight-owner periodic cube and a 27-owner three-dimensional jittered cube. Values for owner index i are `[((13i²+3i+7) mod 31−15)/16, ((5i²+17i+3) mod 37−18)/16, ((7i²+11i+5) mod 41−20)/16]`. Also use each real-owner unit column, constants, analytic Fourier and parity modes. Report the native face values and field, orientation, Euclidean transpose, coalesced volume-weighted diagonal, all-volume mean, independent normal closure and full volume-weighted singular spectra on the small cases. The reference face integration uses the three degree-two triangle quadrature points on the actual polygon fan. Independently fit the sample values using the declared support and weighted design. The identity tolerance is 1e-12 scaled and the configured-mean tolerance is 1e-9 of the initial field scale. Periodic self-faces retain an observable face value and their paired curl exchange cancels.

## Spatial test

Use the original O02 Fourier potential and a fixed imposed field. Compare the estimated field with the analytic curl integrated over the actual cell. On uniform cubes the integral of a product of a sine with a cosine on two distinct axes has the exact common factor sinc(π/N)² relative to its centroid value. For the irregular meshes use independent clipped-cell integration with certified truncation or a tighter quadrature and an explicit uncertainty bound. The unit-box meshes have N=8,16,32 and include genuine xyz jitter. Use the specified mix64 generator with seeds 1, 2 and 3, each at zero mean and at (0.3, −0.2, 0.4). Also repeat the three published M2b jitter families to compare with their observed initial mean failures. Record each input and its array hashes. The finest-three log-log L1 slope must reach 1.8, the finest normalized L1 must be at most 0.1 and the reference uncertainty must be at most 1e-5 of the field scale. Keep signed and unsigned mean and independent divergence measures. Apply the shared-face candidate's original thresholds to all predeclared cases. A ridge, stencil or derivative event requires separate evidence.

## Moving and coupled acceptance

Adoption requires the full CF-MEAN/SPACE suite, the smooth shared-face derivative F5–F9, stage consistency, flux budgets, boost, event-resolved physical exchanges and field-energy partition on actual moving geometries. An initialization result or convergence of a static Fourier field establishes only that part of M2c. The geometry derivative of the point reference is separately named and uses different physics. The first coupled finite-step experiment measures uniform states, a translating helix and oblique Alfvén waves on prescribed periodic meshes. [Finite-step measurements](M2C_SMOOTH_STEP.md#measured-results).

## Shared-face derivative on a smooth branch

Use the exact same archived 27-owner jittered input and every persistent owner vector from the dense-map fixture. Set the prescribed velocity of site i to `[((7i+3) mod 13−6), ((5i+1) mod 11−5), ((3i+2) mod 17−8)]/128`. At time zero and at both endpoints of every central difference, retain every exactly active supporting bisector and full face key. Use half-steps 1/128 through 1/8192, and identify an interval crossing any vertex/support switch as ineligible for a smooth derivative. The registered smooth-branch tests require the reconstructed field, face area vectors, centroids and polygon covariances to agree with rebuilt differences to 1e-7 at the finest eligible step, with second-order decrease above a separately measured reference roundoff floor. Record the local inverse sensitivity and the unscaled differences. Require the differentiated volume-weighted mean identity, fixed-ray transpose and constants to 1e-12 scaled. For the single-owner torus a common translation leaves all shape quantities fixed. At a nonrigid, multiply supported vertex the initial implementation must report an unresolved derivative. An event controller and interval certificate are separate prerequisites for advancing a physical step across a topology change.

## Unequal-wave cubic diagnostic

The original equal-wave divergence decrease stays separately recorded. Before obtaining the diagnostic outputs, fix a zero-mean potential with only its z component nonzero, sin(2πx) sin(4πy), on the same 8³, 16³ and 32³ cubic meshes. Its analytic cell-average field has the centroid curl multiplied by sinc(π/N) sinc(2π/N), where sinc(u) = sin(u)/u. Measure all three independent divergence RMS values, independently recompute the arithmetic face flux from the returned field, and report every successive change. The unequal-wave arithmetic and cell-fit residuals must exceed the previously specified cubic roundoff scale and decrease on both refinements to demonstrate sensitivity. This diagnostic does not amend the registered CF-SPACE verdict.

For the analytic moving-sample control, use A_k = sin(2π c_j) cos(2π c_l), with cyclic axes j and l and each cell's actual centroid c. Differentiate A along the independently computed centroid velocity. Compare Ċ A + C dA/dt with separate endpoint reconstructions of both the sample and polygon. Use the same halving sequence and finest 1e−7 threshold. Archive the full three-epoch face keys, vertex supports, stencil supports and the two endpoint and predicted words for each entry. Report any switched interval separately.
